# 易语言（32 位 / 64 位）调用 ysc_sdk.dll 示例

本目录演示如何用**易语言**直接调用 `ysc_sdk.dll`，不再用易语言重复实现串口
驱动、波特率切换、YSC 协议帧编解码——这些全部由 DLL 完成。

## 1. 选对 DLL（关键）

易语言进程是几位，就只能加载几位的 DLL：

| 易语言版本 | 要用的 DLL | 仓库内路径 |
|---|---|---|
| 易语言（32 位，主流） | **32 位 DLL** | `ysc_8k_driver/bin/Win32/Release/ysc_sdk.dll` |
| 易语言（64 位，6.x 起支持） | 64 位 DLL | `ysc_8k_driver/bin/x64/Release/ysc_sdk.dll` |

> DLL 用静态 CRT（/MT）编译，**目标机不需要安装 VC 运行库**。
> **调用约定是 stdcall（易语言/VB6/Delphi 的默认约定），易语言里不用设"调用方式"，直接声明就能调，不会报"堆栈错误"。**（x64 下只有一种约定，同样无需设置。）

## 2. 命令声明表（直接粘贴到易语言）

打开易语言 → 左侧"程序"面板 → **Dll命令** → 粘贴下面整段（stdcall，易语言默认
即匹配，**参数类型照抄即可，不用管调用方式**）：

```
.版本 2

.DLL命令 ysc_取SDK版本_, 整数型, "ysc_sdk.dll", "Ysc_SupportedBaudrates"
    .参数 波特率个数, 整数型, 传址
' 说明：取 SDK 版本字符串用 Ysc_SdkVersion（返回文本型指针，见下）；取支持波特率列表用上面这条（返回第一个元素的指针）。
```

> 易语言的"Dll命令"里**返回指针**和**文本型参数**有些版本不便直接表达，下面给出
> 一份**最常用命令**的精简声明（stdcall）。完整接口见
> `ysc_sdk_易语言Dll命令声明.txt`（含 27 个导出函数的逐条声明）。

### 精简常用命令（stdcall）

```
.版本 2

.DLL命令 ysc_取版本_, 整数型, "ysc_sdk.dll", "Ysc_SdkVersion"
' 返回值 = 字符串指针；用 lstrcpyA / 指针到文本号 取出文本

.DLL命令 ysc_列出YSC串口, 整数型, "ysc_sdk.dll", "Ysc_ListPorts"
    .参数 输出缓冲, 文本型, 传址
    .参数 缓冲大小, 整数型
' 成功返回写入字节数（负数=出错）；缓冲里是 JSON 数组

.DLL命令 ysc_列出全部串口, 整数型, "ysc_sdk.dll", "Ysc_ListAllComPorts"
    .参数 输出缓冲, 文本型, 传址
    .参数 缓冲大小, 整数型

.DLL命令 ysc_探测波特率, 整数型, "ysc_sdk.dll", "Ysc_DetectBaudrate"
    .参数 串口名, 文本型
' 返回探测到的波特率；失败返回 0

.DLL命令 ysc_连接, 整数型, "ysc_sdk.dll", "Ysc_Connect"
    .参数 串口名, 文本型, , , "COM7"
    .参数 波特率, 整数型, , , 0   ' 0=自动探测
    .参数 错误缓冲, 文本型, 传址
    .参数 错误缓冲大小, 整数型
' 成功返回句柄(>0)；失败返回 0，错误缓冲里有原因

.DLL命令 ysc_断开, , "ysc_sdk.dll", "Ysc_Disconnect"
    .参数 句柄, 整数型

.DLL命令 ysc_是否已连接, 整数型, "ysc_sdk.dll", "Ysc_IsConnected"
    .参数 句柄, 整数型

.DLL命令 ysc_发送命令_, 整数型, "ysc_sdk.dll", "Ysc_SendCommand"
    .参数 句柄, 整数型
    .参数 JSON命令, 文本型
    .参数 超时毫秒, 整数型
    .参数 返回缓冲, 文本型, 传址
    .参数 返回缓冲大小, 整数型
' 返回>0=成功（返回字节数）；=0=超时无返回；<0=出错

.DLL命令 ysc_查询版本, 整数型, "ysc_sdk.dll", "Ysc_QueryVersion"
    .参数 句柄, 整数型
    .参数 超时毫秒, 整数型
    .参数 返回缓冲, 文本型, 传址
    .参数 返回缓冲大小, 整数型

.DLL命令 ysc_切换波特率, 整数型, "ysc_sdk.dll", "Ysc_SwitchBaudrate"
    .参数 句柄, 整数型
    .参数 新波特率, 整数型
' 成功返回 1，失败返回 0

.DLL命令 ysc_鼠标移动, 整数型, "ysc_sdk.dll", "Ysc_MouseMove"
    .参数 句柄, 整数型
    .参数 X, 整数型
    .参数 Y, 整数型
    .参数 步数, 整数型

.DLL命令 ysc_鼠标按键, 整数型, "ysc_sdk.dll", "Ysc_MouseButton"
    .参数 句柄, 整数型
    .参数 按键掩码, 字节型
    .参数 是否按下, 整数型

.DLL命令 ysc_键盘按键, 整数型, "ysc_sdk.dll", "Ysc_KeyboardKey"
    .参数 句柄, 整数型
    .参数 HID键码, 字节型
    .参数 是否按下, 整数型

.DLL命令 ysc_键盘全释放, 整数型, "ysc_sdk.dll", "Ysc_KeyboardReleaseAll"
    .参数 句柄, 整数型
' 释放所有注入按下的键；也会中止正在进行的打字

.DLL命令 ysc_键盘打字, 整数型, "ysc_sdk.dll", "Ysc_KeyboardTypeString"
    .参数 句柄, 整数型
    .参数 文本, 文本型
' cmd:47 逐字打出一段混合大小写 ASCII 字符串（1..128 字节）。固件读取 PC 下发的
' CapsLock 状态(HID LED 报告)，对字母按 目标大小写 XOR CapsLock 自动决定是否加 Shift，
' 符号/数字不受影响。返回 1=已发送；0=被拒(空串/超 128 字节/未连接/正在打字)。
' 即发即弃：返回后固件仍在逐字打（约每字 40ms），断开连接不影响继续打完。

.DLL命令 ysc_键盘状态, 整数型, "ysc_sdk.dll", "Ysc_KeyboardTypeStatus"
    .参数 句柄, 整数型
    .参数 超时毫秒, 整数型
    .参数 返回缓冲, 文本型, 传址
    .参数 返回缓冲大小, 整数型
' cmd:48 查询打字进度（同步等返回）。返回缓冲里是
'   {"code":200,"message":"type_status","data":"{\"busy\":0,\"remaining\":0,...}"}
' busy=0 表示空闲或已打完。用于长文本切片循环打印（见下）。

.DLL命令 ysc_跳转IAP, 整数型, "ysc_sdk.dll", "Ysc_JumpIAP"
    .参数 句柄, 整数型

.DLL命令 ysc_取错误_, 整数型, "ysc_sdk.dll", "Ysc_LastError"
' 返回错误描述字符串指针
```

## 3. 完整调用示例（易语言代码）

```
.版本 2
.支持库 spec

.子程序 _按钮_连接_被单击
    .局部变量 错误, 文本型
    .局部变量 句柄, 整数型
    .局部变量 版本返回, 文本型
    .局部变量 长度, 整数型

    ' 1) 连接 COM7，波特率 0=自动探测
    错误 ＝ 取空白文本 (512)
    句柄 ＝ ysc_连接 (“COM7”, 0, 错误, 512)
    .如果 (句柄 ＝ 0)
        信息框 (“连接失败：” ＋ 错误, 0, , )
        返回 ()
    .否则
        信息框 (“连接成功，句柄=” ＋ 到文本 (句柄), 0, , )
    .如果结束

    ' 2) 查询设备版本（同步等待返回）
    版本返回 ＝ 取空白文本 (4096)
    长度 ＝ ysc_查询版本 (句柄, 1500, 版本返回, 4096)
    .如果 (长度 ＞ 0)
        信息框 (“版本响应：” ＋ 版本返回, 0, , )
    .否则
        信息框 (“版本查询超时/失败”, 0, , )
    .如果结束

    ' 3) 发任意 YSC 命令（这里示例：取手柄映射 cmd:101）
    长度 ＝ ysc_发送命令_ (句柄, “{” ＋ #引号 ＋ “cmd” ＋ #引号 ＋ “:101}”, 1500, 版本返回, 4096)

    ' 4) 鼠标移动（即发即弃，不等返回）
    ysc_鼠标移动 (句柄, 100, 100, 1)

    ' 5) 用完断开
    ysc_断开 (句柄)
```

### 键盘打字示例（cmd:47，混合大小写）

```
.版本 2
.支持库 spec

.子程序 _按钮_打字_被单击
    .局部变量 错误, 文本型
    .局部变量 句柄, 整数型
    .局部变量 待打字, 文本型
    .局部变量 结果, 整数型

    待打字 ＝ “Wasd123A123vciseC”    ' 大小写由固件按 CapsLock 自动处理，无需自己拼 Shift

    ' 1) 连接（COM 口按实际改；0=自动探测波特率）
    错误 ＝ 取空白文本 (512)
    句柄 ＝ ysc_连接 (“COM7”, 0, 错误, 512)
    .如果 (句柄 ＝ 0)
        信息框 (“连接失败：” ＋ 错误, 0, , )
        返回 ()
    .如果结束

    ' 2) 打字（即发即弃；固件逐字按下/松开，字母按需自动加左 Shift）
    '    前提：Right 侧已接真实键盘（否则设备忽略命令、不产生按键）
    结果 ＝ ysc_键盘打字 (句柄, 待打字)
    .如果 (结果 ＝ 0)
        信息框 (“打字被拒：空串或超过 128 字节”, 0, , )
    .否则
        ' 字符串较长时，给固件一点时间逐字打完再断开（每字约 40ms）
        延时 (取文本长度 (待打字) × 40 ＋ 300)
        信息框 (“已发送打字命令”, 0, , )
    .如果结束

    ' 3) 用完断开
    ysc_断开 (句柄)
```

> 打字时大小写怎么来？固件读取 PC 当前 CapsLock 状态：CapsLock 关时大写字母自动加
> Shift，CapsLock 开时小写字母自动加 Shift（符号/数字永远不变）。所以同一句
> `Wasd123A123vciseC`，CapsLock 关时打出 `Wasd123A123vciseC`，CapsLock 开时打出
> `wASD123a123VCISEc`——与你在键盘上手动敲的效果完全一致。

### 无限长度打印（cmd:47 切片 + cmd:48 轮询）

单次 `ysc_键盘打字` 最多 128 字节。要打更长的文本，按 100 字节切片，每片打完
（用 cmd:48 查到 `busy=0`）再发下一片，就能打印任意长度。原理：宿主每次发送前会
清空接收缓冲，所以异步的 `type_done` / 鼠标上报帧不会和查询响应错位。

```
.版本 2
.支持库 spec

.子程序 打印长文本
    .参数 句柄, 整数型
    .参数 待打文本, 文本型
    .局部变量 起始, 整数型
    .局部变量 总长, 整数型
    .局部变量 片段, 文本型
    .局部变量 返回, 文本型
    .局部变量 忙位置, 整数型

    起始 ＝ 1
    总长 ＝ 取文本长度 (待打文本)
    返回 ＝ 取空白文本 (4096)

    .判断循环首 (起始 ＜＝ 总长)
        片段 ＝ 取文本中间 (待打文本, 起始, 100)    ' 每片 100 字节（留余量，< 128 上限）
        起始 ＝ 起始 ＋ 100

        ' 1) 同步打出本片（消费 typing_started；片段内不能含 " 或 \，否则要先转义）
        ysc_发送命令_ (句柄, “{” ＋ #引号 ＋ “cmd” ＋ #引号 ＋ “:47,” ＋ #引号 ＋ “s” ＋ #引号 ＋ “:” ＋ #引号 ＋ 片段 ＋ #引号 ＋ “}”, 1000, 返回, 4096)

        ' 2) 轮询 cmd:48 直到 busy=0（响应里 \"busy\":0 的 0/1 在 "busy" 后第 7 个字符）
        .判断循环首 (真)
            ysc_发送命令_ (句柄, “{” ＋ #引号 ＋ “cmd” ＋ #引号 ＋ “:48}”, 500, 返回, 4096)
            忙位置 ＝ 寻找文本 (返回, “busy”, )
            .如果真 (忙位置 ＞ 0)
                .如果真 (取文本中间 (返回, 忙位置 ＋ 7, 1) ＝ “0”)
                    跳出循环 ()
                .如果真结束
            .如果真结束
            延时 (20)
        .判断循环尾 ()
    .判断循环尾 ()
```

> 上面用文本查找提取 `busy`（够用）。若片段里含 `"` / `\` 等字符，发 cmd:47 前要按
> JSON 规则转义；更稳妥的做法是用精易模块的 JSON 解析来取 busy 和构造 payload。

## 4. 注意事项

- **DLL 放哪**：把对应位数的 `ysc_sdk.dll` 放到易语言工程目录，或编译后的 exe 同
  目录；也可放 `C:\Windows\System32`（不推荐）。
- **文本型参数**：所有 `文本型, 传址` 的输出缓冲，调用前必须用 `取空白文本(N)` 预
  分配，否则 DLL 写入会越界。
- **JSON**：YSC 协议用 JSON，易语言里用文本拼接即可（注意双引号用 `#引号` 或 `“”`）。
- **调用方式**：DLL 是 **stdcall**（易语言默认约定），不用设；如果你之前手动改过
  某条命令的"调用方式"，请改回默认/stdcall，否则会"调用DLL命令后发现堆栈错误"。
- **多设备**：`Ysc_Connect` 每次返回独立句柄，可同时连 Left/Right 两个 dongle。
