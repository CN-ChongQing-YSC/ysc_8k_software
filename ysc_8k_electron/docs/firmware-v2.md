# 8K V2固件更新 (YSC 8K v2 / towmcu)

侧边栏「8K V2固件更新」面板用于给 **v2 8K V2** 板（两片 MCU 经 USB
枚举，VID `1A86` / PID `FE0C`）在线升级固件，**无需外接烧录器**。v1 单芯片板
请用侧边栏「固件更新」面板。

## 准备

1. 用 SWD 烧录器至少烧过一次 Left + Right APP（初次烧录，见项目 CLAUDE.md）。
   之后两片芯片会以 `TOWMCULEFT` / `TOWMCURIGHT` 枚举为 CDC 串口。
2. 准备好加密固件：`convert/left/ysc_left_app.bin`、`convert/right/ysc_right_app.bin`
   （由 `convert/{left,right}/FirmwareEncryptionTool.exe` 生成）。**不要**选
   `obj/*.enc.bin` —— 那是另一套加密器，不兼容。

## 操作步骤

1. 点侧边栏「8K V2固件更新」图标（两个并列矩形）。
2. 端口下拉会自动列出所有匹配 `VID 1A86 / PID FE0C` 的 CDC 设备，格式：
   ```
   [Left]  COM24 — TOWMCULEFT
   [Right] COM28 — TOWMCURIGHT
   ```
   若列表为空，点「刷新」，或检查 USB 连线 / 驱动。
3. 选中要升级的那侧（如 `[Left] COM24`），点「查询版本」确认在线 ——
   应显示 `[APP] ysc-towmcu-L v1.0`。
4. 「左固件」「右固件」分别「浏览」选对应的 `.bin` 文件。
5. 点「升级左」（或「升级右」）。日志会逐条显示：

   ```
   [22:30:01] 8K V2固件更新工具就绪 ...
   [22:30:15] 确认设备模式 ...
   [22:30:15] [APP] ysc-towmcu-L v1.0
   [22:30:15] 设备在 APP 模式 — 发送进入下载模式 (cmd 50) ...
   [22:30:17] 寻找 IAP 端口 (TOWMCUIAP) ...
   [22:30:17] IAP 端口: COM31 (YSC-IAP)
   [22:30:17] 发送擦除命令 ...
   [22:30:18] 擦除成功
   [22:30:18] 开始编程 (600 块) ...
   [22:30:21] 编程完成, 耗时 3.12s (11.0 KB/s)
   [22:30:21] 开始校验 ...
   [22:30:23] 校验通过, 耗时 1.85s
   [22:30:23] 发送结束命令 ...
   [22:30:23] 固件升级完成! 设备将跳转到 APP ...
   ```
6. 升级完成后端口列表会自动刷新 —— 设备应重新枚举为 `[Left]`（不是 `[IAP]`）。
   再「查询版本」验证新固件已运行。
7. 对另一侧重复。

## 按钮

| 按钮 | 作用 |
|---|---|
| 刷新 | 重扫 CDC 端口 |
| 查询版本 | 在选中端口发 `{"cmd":132}`，回 APP/IAP 模式与版本串 |
| 进入下载模式 | 发 `{"cmd":50}`，让设备进入 IAP（`TOWMCUIAP`），不升级。用于诊断 / 手动停放 |
| 升级左 / 升级右 | 完整流程：进 IAP → ERASE → PROGRAM → VERIFY → END |
| 取消 | 中断当前升级（在下一个块边界生效） |

## 升级失败 / 排错

- **未找到 IAP 端口**：发 `cmd:50` 后 10 秒内没枚举出 `TOWMCUIAP`。拔插 USB、
  确认设备没卡死，再试「进入下载模式」。
- **编程块 N: 响应超时**：CDC 偶发延迟。驱动已内置 3 次重试 / 500ms 超时；若仍
  失败，换一根 USB 线 / 换一个 USB 口，避免 hubs。
- **校验块 N 失败 — 固件不匹配**：选错了 `.bin`（比如把左固件刷到右芯片）。
  检查文件路径与芯片侧是否对应。
- **IAP 模式下设备不返回**：确认选的端口标签是 `[IAP]`（`TOWMCUIAP`），不是
  `[Left]`/`[Right]`。在 IAP 端口上「升级左」会直接走 ERASE/PROGRAM/VERIFY/END。

## 技术细节

- CDC 波特率无关（USB），驱动开 115200，不切换波特率。
- 升级期间独占该 COM 口；若该端口恰好也是 UART「串口连接」面板的当前端口，
  驱动会先断开、升级完再自动重连。
- 用词约定：UI / 日志里只说「8K V2 / 8K V2」，不暴露 MCU 具体型号。

协议帧格式与命令调用示例见 `../ysc_8k_driver/README.md`。
